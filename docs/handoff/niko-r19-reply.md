## 1. Публичные пиры Yggdrasil (§19)

С нашей стороны менять ничего не нужно.

- Нода уже принимает до 8 пиров (`MaxYggdrasilPeers`): `rayctl service set ygg peers=…`.
- Схемы: `tls`, `quic` (только по IP), `wss`, `ws`, `tcp`.
  - `tcp` и `ws` оператор задать может. Но линк в них открытый, и протокол Yggdrasil виден на проводе. Если клиент
    их не берёт или ставит последними — это верно.
- В инструкции ноды (`docs/10-quickstart-debian13.md` §8) теперь советуем до 8 разных пиров: у разных операторов, в
  разных странах, вперемешку `tls`, `quic`, `wss`. Объясняем, что клиент выбирает из них сам.
- На тестовой ноде для VPS-CHECK заведём 8 пиров, а не два.

## 2. Что нового на сервере для вас

- **v0.6.0** вышел: `-supervise`, `-run`, `service cert`. Закрепление можно переносить на его тег.
- **В ветке, к v0.7.0:** проверка хоста перед установкой (`rayctl check`, `bootstrap.sh -check`). Касается только

## 3. Предложение: диагностика сети в клиенте

**Что уже есть у клиента.** «Проверить канал» отвечает, что работает в этой сети: по профилю — скорость TCP,
потери и RTT UDP, по пирам Yggdrasil — задержка. Watchdog переключает профили, подсказки задают начальный порядок.

**Чего не хватает пользователю.** Ответа на вопрос «что оживёт, если поменять параметры». Предлагаем режим
«Диагностика сети»: матрица «профиль × вариант», результат — в экспорт отладочной информации и в сводку (с
согласия). Ниже варианты, которые нода действительно умеет — перебирать имеет смысл только их.

| Что | Варианты, которые даёт нода |
|---|---|
| SPA | носитель UDP или TCP; порты слотов ротируются, порт задаёт сам клиент |
| REALITY | текущие ключи `link`, следующие `next.link` (с `from`), прежние из прошлой подписки — ещё 2 дня после смены |
| Hysteria2 | hy2-masq или hy2-obfs (salamander); Brutal выключен или с темпом из замера; потолки ноды — `up_mbps`/`down_mbps` |
| naive | HTTP/2 по TCP 443 или QUIC по UDP 443 |
| DoH | по TCP 443 (h2) или DoH3 по UDP 443 |
| DNS-туннели | dnstt или masterdns; резолвер — на стороне клиента: системный, публичные, оператора |
| Yggdrasil | напрямую (`niko-ygg`) или через публичные пиры (`niko-ygg-via`, до 8) |
| TCP | `down` разного объёма находит порог, на котором поток встаёт (`tcp_stall_kib`: 8, 16, 32, 64, 128 КиБ) |
| UDP | эхо датаграммами разной длины (от 36 байт) находит MTU пути: нода фрагменты отбрасывает (R4-9), а QUIC нужно 1200+ |

**Чего нода не умеет, и перебирать это бесполезно:**
- другие порты для сервисов: только 443 (TCP, UDP) и 53 (UDP);
- port hopping Hysteria2;
- другие имена SNI в пределах одного набора ключей REALITY.

**Что может дать сервер под этот режим.**
- Эндпоинт замера уже отвечает на всё из таблицы (`probe-v1.md`).
- Если нужен отдельный бюджет на диагностику — сейчас 1 ГиБ на устройство в сутки на все замеры — скажите, сколько.
- Если нужна отдельная корзина в сводке («ожил с вариантом X»), это новое поле `probe-v1` §6. Поле может быть
  только из закрытого списка: свободный текст в сводку не пускаем.
