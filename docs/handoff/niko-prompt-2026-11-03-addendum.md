## 1. yggdrasil-go: патч `LinkDialer` теперь в форке

- Патч перенесён из `arngory/sing-box/third_party/yggdrasil-go` (0.5.14) в `arngory/yggdrasil-go`, ветка `develop`
  ([#1](https://github.com/arngory/yggdrasil-go/pull/1), коммит `0db15d4`, база — 0.5.15).
- API тот же: `core.LinkDialer{DialContext, ListenPacket, TLSClient}` — опция `core.New`.
- Отличия от вендоренной копии (из-за 0.5.15):
  - QUIC берёт `tlsconfig` с `tls_sni` на каждый дозвон;
  - ws и wss с хуком не вызывают `dialerFor`, устаревшее поле `Dial` у транспорта убрано.
- Новый тест в форке — `TestLinkDialer`: линки `tcp`, `tls`, `ws`, `quic` идут через хук; для TCP хук получает имя
  без разрешения, для QUIC — адрес.
- Что сделать в `arngory/sing-box`:
  - заменить `third_party/yggdrasil-go` на

    ```
    replace github.com/yggdrasil-network/yggdrasil-go => github.com/arngory/yggdrasil-go v0.5.16-0.20261103204312-0db15d43777a
    ```

  - убрать копию.
  - 0.5.15 требует Go 1.26 и `github.com/quic-go/quic-go` v0.64.1. Это upstream quic-go, не `sagernet/quic-go`;
    проверь, что сборка с `with_yggdrasil` не конфликтует.
- niko-server уже на форке: [#8](https://github.com/arngory/niko-server/pull/8), релиз `v0.6.1`. Поведение и конфиги
  не изменились.

## 2. Публичные пиры Yggdrasil — `niko-ygg-via` (R4-18)

У ноды можно включить публичные пиры (`rayctl service set ygg peers=...`). По умолчанию их нет. Если они включены,
профиль Yggdrasil несёт их повторяемым параметром `niko-ygg-via`. Подробно — `niko-ygg-note.md` §1а,
формат — `subscription-v1.md` §4.

- Сначала прямой пир из `niko-ygg`. Пиры из `niko-ygg-via` — только когда прямой не подключается.
- Узел клиента входящих не принимает: в общей сети его адрес виден всем.
- Постквант на линке к публичному пиру не гарантирован. `inner` с `encryption` остаётся и подтверждает ноду.
- Если параметра нет — путь только прямой, как сейчас.

## 3. REALITY: перекрытие ключей при смене (R4-19)

Менять в клиенте ничего не нужно, сервер стал терпимее. Таблица в `niko-r4-note.md` §1 обновлена.

- Новые ключи нода включает за 2 минуты до `from`.
- Прежние ключи (и прежнее имя) нода принимает ещё 2 дня после `from`.
- Исключение — `rayctl service rotate -now` (утечка ключа, блокировка имени): после него прежние сразу не работают.
- Порядок в клиенте прежний: `link` → `next.link` с `from` → назад к `link` → перезапрос подписки.
