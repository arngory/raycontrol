# 04. Направления работ и этапы

Статус: **черновик для согласования**.

Работа разбита на направления (WS). Каждое направление закрывает свою часть находок аудита
([00-legacy-audit.md](00-legacy-audit.md)) и опирается на решения из
[01-architecture.md](01-architecture.md), [02-security-model.md](02-security-model.md) и
[03-protocols.md](03-protocols.md).

## Направления

### WS-0. Срочные исправления v0 (опционально)

Только если v0 сейчас где-то работает и до готовности новой версии его нельзя выключить.

- [ ] Hysteria: `auth.type: http` или параметризованный запрос вместо подстановки в SQL — L-01
- [ ] Xray: routing `geoip:private` → blackhole — L-02
- [ ] `del-user`: убрать `-q` при подсчёте или считать через `RETURNING` — L-10
- [ ] Включить `nftables.service`, проверка пустого `SSH_PORT` — L-13, L-14
- [ ] Лог `0600`, без паролей — L-03

- [ ] Allow-наборы по инстансам, профили public/gated
- [ ] Port hopping для `hysteria@obfs` средствами `rayspa`

- [ ] Аварийный доступ к SSH

## Открытые вопросы

1. **Профили public/gated.** Согласны, что VLESS REALITY (TCP 443) и Hysteria2 masquerade (UDP 443)
   по умолчанию публичные? Иначе маскировка под сайт теряет смысл и сторонние клиенты не подключатся.
2. **Один сервер или контроллер + узлы.** Сейчас закладываем один узел с границей под будущий контроллер.
   Если несколько серверов нужны скоро, `rayd` сразу делится на controller и node-agent.
3. **Go + ConnectRPC** для своих компонентов и API — подтверждаете?
4. **Будущий клиент:** платформы (desktop, Android, iOS) и роль: только наш клиент для gated-доступа или
   полноценный VPN-клиент? Влияет на формат SPA и на объём API.
5. **Шифрование базы на диске:** нужно ли и чем (age, systemd credentials, TPM).
6. **Домен обязателен?** Self-steal требует своего домена. ACME по умолчанию HTTP-01, DNS-01 у любого провайдера опционально.
7. **Стук:** статическая последовательность или TOTP-порты.
8. **XanMod:** оставлять опцией или ограничиться sysctl на стоковом ядре.
