# 07. Вопросы перед реализацией

Ответы на эти вопросы фиксируют базу. У каждого вопроса есть вариант, который предлагается по умолчанию,
и отметка, что он блокирует:

- **M0** — нужен ответ до начала каркаса (этап M0);
- **Mx** — нужен до соответствующего этапа;
- без отметки — можно решить по ходу.

Формат ответа: номер вопроса и выбранный вариант или свой. После ответов решения переносятся в
соответствующие документы, а вопрос помечается закрытым.
