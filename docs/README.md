# raycontrol v2: проектная документация

Документы описывают пересборку raycontrol: набор CLI-инструментов с API для будущего клиента,
многоуровневым периметром (port-knocking → SPA → аутентификация в сервисе) и изоляцией компонентов по принципу zero trust.

| Документ | О чём |
|---|---|
| [00-legacy-audit.md](00-legacy-audit.md) | Аудит текущей версии v0: находки с ID `L-xx`. |
| [01-architecture.md](01-architecture.md) | Компоненты, язык, структура репозитория, модель данных, интерфейс движков. |
| [02-security-model.md](02-security-model.md) | Угрозы, эшелоны защиты, knock + SPA, профили public/gated, zero trust между компонентами. |
| [03-protocols.md](03-protocols.md) | Протоколы и движки, self-steal, карта портов. |
| [04-roadmap.md](04-roadmap.md) | Направления работ с привязкой к находкам аудита, этапы, открытые вопросы. |

Статус: черновик для согласования. Код v0 (`ray.sh`, `uninstall.sh`) пока остаётся на месте.
