# 00. Аудит текущей версии (v0)

Разбор `ray.sh` и `uninstall.sh` на коммите `3a4912c`. Номера строк указаны для этого коммита.
У каждой находки есть ID (`L-xx`); в [04-roadmap.md](04-roadmap.md) указано, в каком направлении работ она закрывается.

Как проверялось: код прочитан целиком, shellcheck (не видит код внутри heredoc), `nft -c` на сгенерированных правилах,
поведение `psql` проверено на живом PostgreSQL.

## Что делает v0

Одноразовый bash-установщик для Debian/Ubuntu:

- Xray: VLESS+TLS+Vision (TCP 443) и Trojan+TLS (TCP 8443), сертификат Let's Encrypt через DNS-01 Cloudflare;
- Hysteria2 (UDP 3478) с salamander, авторизация через `command`-скрипт с запросом в PostgreSQL;
- PostgreSQL как хранилище пользователей;
- nftables: всё закрыто, доступ к прокси и SSH через трёхступенчатый port-knocking;
- опционально ядро XanMod;
- `raycontrol` — CLI управления, хранится heredoc-строкой внутри `ray.sh`.

## Безопасность

| ID | Где | Проблема | Критичность |
|---|---|---|---|
| L-01 | `ray.sh:969` | SQL-инъекция в авторизации Hysteria: пароль клиента из сети подставляется в `WHERE password = '$AUTH'`. Пароль `' OR '1'='1` проходит авторизацию. На каждое подключение запускается два `psql`. | критично |
| L-02 | `ray.sh:877-899` | В Xray нет routing-правил: пользователи прокси достают `127.0.0.1:5432`, `169.254.169.254` (метаданные облака) и любые локальные сервисы. | критично |
| L-03 | `:75`, `:604`, `:147`, `:252`, `:319-321` | Секреты утекают: лог `0644` содержит пароли новых пользователей, токен Cloudflare вводится видимым текстом, пароли передаются в argv `psql -c`. | высокая |
| L-04 | `:908`, `:1000-1001` | Все сервисы работают от `nobody`; `nobody` добавлен в `ssl-cert`; конфиги с секретами принадлежат `nobody`. | высокая |
| L-05 | `:79-127` | Откат при ошибке удаляет все пакеты `postgresql*`, `/root/.secrets` целиком, всю папку post-хуков LE и сбрасывает чужие правила nftables. | высокая |
| L-06 | `:651-662` | Бэкапы со всеми секретами не шифруются. | средняя |
